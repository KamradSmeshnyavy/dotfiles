# Cyber Pastel Cyan — Omarchy Theme

Пастельная кибер-хакерская тема с циановым акцентом.

| Цвет | Значение |
|------|----------|
| Фон | `#1a1b2e` мягкий тёмно-фиолетовый |
| Акцент | `#89ddff` пастельный циан (cyberpunk) |
| Зелёный | `#a8d8b9` |
| Текст | `#e2dff0` |

## Установка

```sh
omarchy theme set cyber-pastel-cyan
```
