# DOT-MATRIX: загрузка и вход

Plymouth- и SDDM-темы к [`../dot-matrix`](../dot-matrix/README.md). Лежат вне каталога темы: omarchy копирует тему
в `~/.local/state/omarchy/current/theme` при каждой смене, а сюда ничего не нужно — ставится вручную через `sudo`
(команды в README темы). `sddm/fonts` ссылается на шрифты в плагине `kamradsmeshnyavy.customizer`.
