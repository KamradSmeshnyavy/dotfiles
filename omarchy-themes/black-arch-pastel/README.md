# Pastel Blackarch — Omarchy Theme

Мягкая пастельная версия темы Black Arch. Те же цвета, что и в black-arch-my-vision, но с пониженной насыщенностью и мягко-чёрным фоном.

| Цвет | Blackarch | Pastel Blackarch |
|------|-----------|------------------|
| Фон | `#000000` | `#14161a` |
| Текст | `#e6e1cf` | `#dcd7cf` |
| Акцент | `#36a3d9` | `#6bb8e0` |
| Красный | `#f07178` | `#e8a0a0` |
| Зелёный | `#b8cc52` | `#b8cc80` |
| Жёлтый | `#e6b673` | `#e8c890` |
| Магента | `#ffee99` | `#f0ddaa` |
| Циан | `#36a3d9` | `#7ec8e3` |

## Установка

```sh
omarchy theme set pastel-blackarch
```
