# Pastel Deep Teal — Omarchy Theme

Глубокая тёмно-бирюзовая тема в пастельных тонах. Вдохновлена корпоративным стилем.

| Цвет | Значение |
|------|----------|
| Фон | `#0d1820` глубокий teal-black |
| Акцент | `#4a9eb5` мягкий teal |
| Seafoam | `#6bb5a7` |
| Текст | `#d6e4ec` |

## Установка

```sh
omarchy theme set pastel-deep-teal
```
