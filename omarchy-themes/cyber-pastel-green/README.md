# Cyber Pastel Green — Omarchy Theme

Пастельная кибер-хакерская тема с мятно-зелёным акцентом.

| Цвет | Значение |
|------|----------|
| Фон | `#1a1b2e` мягкий тёмно-фиолетовый |
| Акцент | `#a8d8b9` мятно-зелёный (matrix pastel) |
| Циан | `#89ddff` |
| Текст | `#e2dff0` |

## Установка

```sh
omarchy theme set cyber-pastel-green
```
