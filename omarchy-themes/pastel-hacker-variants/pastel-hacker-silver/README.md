# Pastel Hacker — Omarchy Theme

Хакерская тема в пастельных тонах. Вдохновлена эстетикой взлома, матрицы и CRT-терминалов — но в мягких, пастельных цветах.

| Цвет | Значение |
|------|----------|
| Фон | `#0d0e1a` почти чёрный |
| Акцент | `#dcd7e6` хакерский серебристый |
| Алерт | `#f1948a` пастельно-красный |
| Текст | `#dcd7e6` |

## Установка

```sh
omarchy theme set pastel-hacker
```
