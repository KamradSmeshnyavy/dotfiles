# Themes and app theming

An Omarchy theme sets colours and wallpapers. Here **one theme switch recolours everything**, not only what Omarchy
itself touches.

```sh
just theme                  # list
just theme nothing          # apply (same as `omarchy theme set nothing`)
just theme-from-wallpaper   # a "dynamic" theme from the current wallpaper (matugen; --scheme vibrant, --mode light)
```

Or in the Customizer: Desktop → Theme (with a preview of the palette), or `>theme` in the launcher.

## My themes

Hand-made themes in [`omarchy-themes/`](https://github.com/KamradSmeshnyavy/dotfiles/tree/main/omarchy-themes): Nothing,
DOT-MATRIX, Rose Pine Hacker / Hacker24, Pastel Hacker, Catppuccin Mocha (Efter, Lavender), Nord, Black Arch… Each one
can carry its own app themes in `apps/`, sounds in `apps/sounds/`, a Neovim colour scheme in `nvim/`.

## What follows the theme

| What | How |
|---|---|
| kitty, ghostty | `theme.conf` from the current theme; the Customizer style adds `style.conf` |
| yazi, lazygit, atuin, lla, television, gitui, rmpc, nushell, tmux, fastfetch, fzf | **theme slots** — gitignored symlinks that `omarchy-app-themes` re-points on every theme change ([APP-THEMING](https://github.com/KamradSmeshnyavy/dotfiles/blob/main/omarchy-themes/APP-THEMING.en.md)) |
| Neovim | the theme's own colour scheme from `~/.local/state/omarchy/current/theme/nvim` |
| Zsh | `omarchy-zsh-colors` |
| VS Code | Omarchy's own `omarchy-theme-set-vscode` |
| GTK, Qt (qt6ct), Ghidra, Vesktop, Telegram | generated by `omarchy-app-themes` |
| Firefox, Helium | Dark Reader, Stylus, Surfingkeys, Firefox `userChrome.css` — see [Browsers](Browsers) |
| Shell plugins | Quickshell colours from the theme; the DOT-MATRIX palette follows it too |
| Boot | `just boot-theme` — Limine and Plymouth in the theme's colours (needs sudo) |

It all runs from Omarchy's `theme-set` hook (`omarchy-themes/hooks/theme-set`), so nothing has to be done by hand.

## Making a theme

Theme colours live in `colors.toml`; per-app files go to the theme's `apps/` (`yazi.toml`, `lazygit.yml`, `tmux.conf`, …).
A theme without them falls back to `omarchy-themes/app-defaults`. After editing, `just app-themes` re-points the slots.
**Never edit the slot files themselves** — change the file inside the theme.
