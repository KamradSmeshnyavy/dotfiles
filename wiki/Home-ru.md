# Omarchy, настроенный плагинами

Эта wiki — практическое руководство к [KamradSmeshnyavy/dotfiles](https://github.com/KamradSmeshnyavy/dotfiles):
система на [Omarchy](https://omarchy.org), где весь вид рабочего стола собран из **отдельных устанавливаемых плагинов
оболочки Omarchy** и управляется одним оверлеем — **Customizer**.

Чтобы всё это получить, копировать мои dotfiles не нужно. Каждый плагин — свой репозиторий:

```sh
omarchy plugin add https://github.com/KamradSmeshnyavy/omarchy-customizer --enable
```
