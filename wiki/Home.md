# Omarchy, customised with plugins

This wiki is the hands-on guide to [KamradSmeshnyavy/dotfiles](https://github.com/KamradSmeshnyavy/dotfiles): an
[Omarchy](https://omarchy.org) setup where the whole look of the desktop is built from **separate, installable Omarchy
shell plugins** and driven by one overlay — the **Customizer**.

You don't have to copy my dotfiles to get any of it. Every plugin is its own repo:

```sh
omarchy plugin add https://github.com/KamradSmeshnyavy/omarchy-customizer --enable
```
