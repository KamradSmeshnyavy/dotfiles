# Стили

Три оси:

- **Тема** — цвета и обои (темы Omarchy).
- **Стиль** — *форма*: геометрия окон, скин бара, дизайн блокировки, скин лаунчера, вид виджетов / OSD / уведомлений,
  анимации, прозрачность, размытие, звуки, Glyph, шрифты.
- **Пресет** — тема + стиль + обои.

Любой стиль работает на любой теме. Применить — Customizer → Пресеты → **Стиль**. Переключатели под списком выбирают,
какие части стиль применяет (`~/.config/omarchy/customizer/style-apply.json`); «Восстановить прежнюю настройку»
откатывает.

| Стиль | Как выглядит |
|---|---|
| **Flat** | чистые сплошные панели, без эффектов |
| **Glass** | полупрозрачные панели с размытием |
| **Liquid Glass** | по мотивам [Vitreus](https://github.com/natepayn3/Vitreus): очень прозрачные панели под сильным сочным размытием, светлый ободок и мягкий блик сверху, скин бара `liquid`, дашборд вытекает из бара каплей и пружинит на место |
| **Fluent** | акрил в духе Windows 11, мягкие углы |
| **Paper** | листы бумаги: рваный край, зерно, полоска скотча цвета акцента, рукописный Caveat, статичный шейдер бумажного зерна на весь экран; светлые темы — белая бумага, тёмные — крафт / графит |
| **Neon** | свечение акцента, скин бара `neon`, шейдер строк развёртки |
| **Neumorph** | мягкий рельеф, скин бара `soft` |
| **Brutal** | толстые рамки с жёсткой тенью, скин бара `brutal` |
| **Retro** | 3D-фаска (Windows 9x), скин бара `bevel`, пиксельный профиль шрифтов `retro` |
| **Glyph** | по мотивам [glyph-rice](https://github.com/Nebelung-cloud/glyph-rice): Nothing OS на плавающей пилюле слева (скин `glyph-pill`, раскладка `glyph-left` с RunCat и таймером фокуса), домашний экран `glyph` (точечные часы, бенто из круглых и квадратных плиток), Deck из-под нижнего края, OSD подсветкой по краю, контурная подсветка Glyph, переключатель обоев `glyph` (превью на весь экран собирается из точек; вид обоев точки / серое / цвет) с переходом `dotwave`, экран блокировки glyph-rice (дизайн `glyph`), быстрые настройки Quick на Super+M (`settingsPanel: quick`), лаунчер glyph-rice (скин `glyph`: панель по центру, чипы режимов, круги с точечными иконками, Charms и калькулятор цифрами Doto), профиль шрифтов `nothing`; пресет **Glyph** на теме `nothing-glyph-dark` (палитра glyph-rice) |
| **DOT-MATRIX** | вид Nothing OS: точечные шрифты, LED-шкалы, «железные» карточки, окна вплотную к рамке-бортику, профиль шрифтов `pixel` |

Панели виджетов, OSD и уведомлений следуют стилю через `~/.config/omarchy/style.json` (тени, скорость анимаций,
материал, углы, шрифт).

## DOT-MATRIX подробно

DOT-MATRIX перерисовывает всё сразу: бар (скин `dotmatrix` с LED-рабочими столами), панели трея / Wi-Fi / Bluetooth /
звука / дисплея / агентов ([панели DOT-MATRIX](Widgets-OSD-Notifications-ru#панели-dot-matrix)), шторку настроек
(`Super+M`), дашборд, OSD (LED-шкала на 16 точек), уведомления («железные» тосты с пробегом Glyph), экран блокировки и
лаунчер. Палитра следует теме (`{"palette": "theme"}` в `~/.config/omarchy/dotmatrix.json`) или берёт исходные
чёрный / белый / красный (`"mono"`); любую роль можно переопределить в Customizer → Рабочий стол → Виджеты.

**Пресет DOT-MATRIX** дополнительно ставит тему `dotmatrix` и обои.

Свой стиль: [Своё](Make-Your-Own-ru#стиль).
