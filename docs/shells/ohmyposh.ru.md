# Oh My Posh

Краткое описание: Быстрый и настраиваемый движок тем для промпта (prompt engine), поддерживающий любую оболочку.

## Пути
- **Исходники в репозитории:** shells/ohmyposh
- **Линкуется в:** ~/.config/ohmyposh

## Отличия от дефолтной конфигурации и добавленные фичи
- **Дизайн и структура (Blocks):** Используется выравнивание промпта с блоками по правому краю экрана (`alignment: right`). Формат сегментов использует стиль `diamond` (с закругленными краями `` и ``).
- **Единый стиль:** Все активные сегменты используют единый тёмно-синий фон (`#29315A`), различаясь только цветом текста для визуального разделения.
- **Включенные сегменты и цвета:**
  - Имя пользователя (`session`, красный текст `#E64747`).
  - Путь/Папка (`path`, зелёный текст `#3EC669` с иконкой папки ``).
  - Git (`git`, голубой текст `#43CCEA`, стандартная иконка ветки скрыта).
- **Индикация окружений разработки:**
  - Поддерживаются Python (жёлтый `#E4F34A`), Go (голубой `#7FD5EA`), Node (зелёный `#42E66C`), Ruby и Java (красный `#E64747`).
  - *Оптимизация:* Для каждого окружения явно отключен опрос версий (`fetch_version: false`), что сильно ускоряет работу промпта и убирает визуальный шум. Иконки выводятся с помощью Nerd Fonts.
