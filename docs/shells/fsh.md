# Fast Syntax Highlighting (FSH)

[🇷🇺 Русский](fsh.ru.md)

Fast, optimised syntax highlighting for Zsh.

## Paths

- **In the repo:** `shells/fsh`
- **Linked to:** `~/.config/fsh`

## What differs from the defaults

- **Theme:** the full Catppuccin Mocha palette (`catppuccin-mocha.ini`).
- **Highlighting:**
  - plain command text `#cdd6f4`;
  - unknown tokens in bold red `#f38ba8`;
  - commands, functions and aliases blue (`#89b4fa`), builtins and precommands mauve (`#cba6f7`);
  - strings green `#a6e3a1`; options (`--help`) teal `#94e2d5`; variables and math peach (`#fab387`).
- **Bracket nesting:** level 1 red (`#f38ba8`), level 2 yellow (`#f9e2af`), level 3 blue (`#74c7ec`).
