# Starship (Omarchy)

[🇷🇺 Русский](starship-omarchy.ru.md)

An alternative Starship config tuned to the Omarchy look.

## Paths

- **In the repo:** `shells/starship-omarchy.toml`
- **Linked to:** set up per shell profile.

## What differs from the defaults

- Based on the main `starship.toml`, adapted to Omarchy's visual style.
- **Path truncation:** `truncation_length = 2`, truncation symbol `…/`.
- **Git status:** custom icons per state (e.g. `⇡${count}` for commits ahead).
- **Character:** success `❯` and error `✗` in bold cyan to match the Omarchy palette.
