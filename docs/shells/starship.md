# Starship

Краткое описание: Кроссплатформенный, быстрый и невероятно настраиваемый промпт (prompt) для командной оболочки.

## Пути
- **Исходники в репозитории:** shells/starship.toml
- **Линкуется в:** ~/.config/starship.toml

## Отличия от дефолтной конфигурации и добавленные фичи
- **Цветовая палитра:** Используется полная палитра `catppuccin_mocha` (цвета rosewater, flamingo, mauve, sky, peach и т.д.).
- **Структура промпта (Format):** Выводится структурированная информация: имя пользователя, хост, директория, ветка git, статус git, время выполнения команды (cmd_duration), окружение python. Всё это визуально разделяется и переносится на новую строку (`$line_break`) перед символом ввода (`$character`).
- **Индикаторы Git:**
  - Ветка отображается серым (bright-black).
  - Состояния репозитория (стакнутые изменения, конфликты, удаления) кастомизированы минималистичными иконками или скрыты для уменьшения шума (например, спрятаны conflicted/untracked/staged/modified).
- **Символы курсора и режимы:** 
  - Символ ввода: `❯` зелёный при успешном завершении прошлой команды, красный при ошибке.
  - В vi/vim-режиме (`vimcmd_symbol`) используется символ `❮` цвета sky.
- **Отображение директорий:** Отображаются в синем (`blue`) цвете с усечением пути до 2 уровней (`truncation_length = 2`, символ замены — `…/`). Имя корневой директории репозитория подсвечивается (`bold cyan`).
- Отключена лишняя пустая строка перед промптом (`add_newline = false`).
