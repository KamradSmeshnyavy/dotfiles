# Zshrc (.zshrc)

Краткое описание: Конфигурационный файл для оболочки Zsh, обеспечивающий автодополнения, шорткаты, алиасы и внешний вид терминала.

## Пути
- **Исходники в репозитории:** `shells/zshrc/.zshrc`
- **Линкуется в:** `~/.zshrc`

## Отличия от дефолтной конфигурации и добавленные фичи
Конфиг Zsh имеет внушительный размер (~24KB) и предоставляет мощную, настраиваемую среду разработчика.

### 🔌 Плагины и Дополнения
- Использует **Oh My Zsh** в качестве основы.
- **zsh-autosuggestions:** Встроены автоподсказки на основе истории (подтягиваются из `/usr/share/zsh/...`). Настроены кастомные хоткеи: `Ctrl+E` для принятия всей подсказки, `Ctrl+W` для выполнения, `Ctrl+L` для принятия по словам.
- Настроены автодополнения для `kubectl`, `aws_completer` и регистронезависимый поиск при табуляции (`zstyle ':completion:*' matcher-list`).
- Поддержка навигации в стиле Vim-биндингов: `Ctrl+K`/`Ctrl+J` для поиска по истории команд.

### 🎨 Промпт (Тема)
- Поддержка кастомных промптов (ранее использовался `p10k`, сейчас, вероятно, передан `Starship` или `Oh My Posh`, конфигурации которых лежат в соседних папках).

### ⌨️ Кастомные Алиасы
Добавлено множество удобных сокращений, заменяющих стандартные утилиты на их современные (TUI/Rust) аналоги:
- `ping` → `gping` (пинг с графиком).
- `cat` → `bat` (просмотрщик с подсветкой синтаксиса).
- `la` → `tree` (дерево директорий).
- `n` → `nnn` (быстрый файловый менеджер).
- `wifi` → `impala` (TUI для сети), `btui` → `bluetui` (TUI для Bluetooth).
- Архивация через `7zz` (`unzipall`, `peek`, `quickzip`).
- **Мощный набор Git-алиасов:** `gc`, `gp`, `gst`, `gco`, `gdiff` и сложный красивый лог (`glog` с графами и цветами).
- Пакетные менеджеры: `buu` (`brew update && brew upgrade`).

### ⚙️ Скрипты и Интеграции
Файл включает множество системных путей (`/opt/homebrew/bin`, `/usr/local/bin`) и специфичные для MacOS и Omarchy переменные окружения, подстраиваясь под систему (`is_macos()`).
