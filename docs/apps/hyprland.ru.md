# Hyprland

Краткое описание: Конфигурация для динамического тайлингового оконного менеджера Hyprland.

## Пути
- **Исходники в репозитории:** `apps/hyprland`
- **Линкуется в:** `~/.config/hypr` (обычно через stow или системные скрипты установки)

## Отличия от дефолтной конфигурации и добавленные фичи
Конфигурация разбита на модульные файлы для удобства поддержки и тесно интегрирована с экосистемой Omarchy.

### 🧩 Модульная структура
- **`hyprland.conf`**: Основной файл импортов.
- **`autostart.conf`**: Запуск процессов при старте (например, `kdeconnectd`).
- **`bindings.conf`**: Огромный набор кастомных шорткатов.
- **`env.conf`**: Переменные окружения.
- **`looknfeel.conf`**: Настройки внешнего вида (окна, анимации).
- **`monitors.conf`**: Настройка мониторов.
- **`hypridle.conf`, `hyprlock.conf`, `hyprsunset.conf`**: Настройки для управления сессией, экраном блокировки и ночным режимом.

### ⌨️ Кастомные бинды (bindings.conf)
Основное управление системой было доработано с интеграцией скриптов JaKooLit и возможностей Omarchy.

**Меню и интерфейсы:**
- `SUPER + SPACE`: Умное меню Rofi (включает вкладки: Поиск приложений, Файлы, Окна, История буфера обмена, Поиск в браузере).
- `SUPER + Z`: Вызов центра уведомлений SwayNC (история сообщений и быстрые настройки).
- `SUPER + ALT + SPACE`: Вызов системного меню `omarchy-menu` (на базе Walker) для управления Wi-Fi, звуком и профилями питания.
- `SUPER + ESCAPE`: Полноэкранное меню выключения ПК (Wlogout).

**Управление стилем и персонализацией:**
- `SUPER + SHIFT + T`: Мощное меню Rofi для выбора обоев. Выводит обои из `~/Wallpapers` в виде красивой сетки с превью. При выборе обои автоматически перекрашиваются утилитой Lutgen под текущую тему, и интерфейс мгновенно перестраивается.
- `SUPER + CTRL + R`: Выбор структурного шаблона (Layout) для меню Rofi.
- `SUPER + ALT + W`: Выбор макета для панели Waybar (более 40 вариантов: сверху, снизу, разделенные).
- `SUPER + CTRL + W`: Выбор структурного стиля (рамки, прозрачность, стекло) для панели Waybar.
- `SUPER + ALT + A`: Мгновенное переключение анимаций Hyprland "на лету" из огромной коллекции кривых Безье.

**Прочие системные функции:**
- Умный запуск терминала с сохранением текущей директории (`SUPER + RETURN` и `SUPER + ALT + RETURN` для Tmux).
- Назначены шорткаты на вызов специфичных приложений (браузер, файловый менеджер, Spotify, Obsidian, 1password, Typora).
### 🎨 Внешний вид
- Используется тайлинговый режим `dwindle`.
- Внедрены продвинутые анимации и кривые Безье от JaKooLit (всё вынесено в `animations.conf`), что обеспечивает "пружинистое" и плавное появление окон.
- Настроены приятные отступы (gaps), закругления окон (`rounding = 10`) и эффекты размытия (blur) для полупрозрачных слоев.
