# borders

[🇷🇺 Русский](borders.ru.md)

A macOS tool that draws borders around windows.

## Paths

- **In the repo:** `apps/borders`
- **Linked to:** `~/.config/borders` (macOS only)

## What differs from the defaults

1. **Style and size:** rounded borders (`round`), width 3.0 px, HiDPI off.
2. **Colours** (Catppuccin Mocha-like):
   - active window: lavender with alpha `0xbbb4befe`;
   - inactive window: surface0 `0xff313244`.
   - Note: the AeroSpace config overrides them on a workspace change to `0xffe1e3e4` / `0xff494d64`, width 5.0.
