# Hammerspoon

Краткое описание: Инструмент автоматизации для macOS, используемый здесь для продвинутого клавиатурного управления мышью (Vim-style).

## Пути
- **Исходники в репозитории:** `apps/hammerspoon`
- **Линкуется в:** Предположительно `~/.hammerspoon` (отсутствует в явном виде в `install.conf.yaml`, возможно, настраивается вручную или через другие скрипты).

## Отличия от дефолтной конфигурации и добавленные фичи

Добавлен кастомный скрипт для управления курсором и кликами с клавиатуры. Модальный режим активируется горячими клавишами (согласно конфигу Karabiner, это `s`, `m`, `spacebar`). При активации на экране появляется оверлей: `-- NORMAL --` или `-- VISUAL MODE --`.

1. **Движение курсора (Mouse Movement):**
   - Навигация по экрану клавишами `h, j, k, l` (малый шаг).
   - Быстрое перемещение с зажатым `Shift + h/j/k/l` (большой шаг).
   - Стрелки влево/вправо также двигают курсор горизонтально.

2. **Скроллинг (Scrolling):**
   - Плавный скроллинг клавишами `u/d` (вверх/вниз) и `w/b` (влево/вправо).
   - Большой скроллинг: `Shift + u/d/w/b`.
   - Средний скроллинг: `Ctrl + u/d`.
   - Стрелки вверх/вниз эмулируют скроллинг.
   - Поддержка настройки направления скролла (`naturalScroll`).

3. **Клики (Clicks):**
   - `a`: Правый клик (Right Click).
   - `i`: Тройной клик левой кнопкой мыши (выделение абзаца/строки).

4. **Визуальный режим (Drag and Drop):**
   - Клавиша `v` включает визуальный режим (зажимает левую кнопку мыши для начала выделения/перетаскивания).
   - Клавиша `Shift + v` делает тройной клик и затем зажимает левую кнопку (для перетаскивания больших блоков текста).
   - Клавиша `y` в визуальном режиме отпускает кнопку мыши и посылает комбинацию копирования `cmd+c`.
