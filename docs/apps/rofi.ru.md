# Rofi

Краткое описание: Сверхбыстрый и кастомизируемый лаунчер окон и приложений, выступающий в роли "швейцарского ножа" для системы.

## Пути
- **Исходники в репозитории:** `apps/rofi`
- **Линкуется в:** `~/.config/rofi`

## Основной функционал

### 🔍 Единая точка входа (Super + Space)
Rofi настроен как мультитул (combi-modi). При вызове вы видите меню, разделенное на вкладки (переключение по `Tab`):
1. **Apps** (Поиск и запуск установленных приложений).
2. **Files** (Файловый менеджер).
3. **Windows** (Быстрое переключение между открытыми окнами).
4. **Clipboard** (Интеграция с демоном `cliphist` для просмотра и декодирования текстовой/графической истории буфера обмена).
5. **WebSearch** (Быстрый поиск введенного запроса в Google).

### 🎨 Динамические цвета и Шаблоны
Как и Waybar, Rofi жестко интегрирован с Omarchy Theme Engine.
В хуке `~/.config/omarchy/hooks/theme-set` прописан вызов Python-скрипта, который "вытаскивает" палитру из текущей темы (`colors.toml`) и собирает из неё файл `~/.config/rofi/wallust/colors-rofi.rasi`.

В папке `apps/rofi/themes/` лежат только структурные файлы макетов (`Layout-*.rasi`). Все они автоматически импортируют сгенерированные цвета Omarchy. Вы можете на лету поменять расположение меню (сделать его на весь экран, компактным, в стиле Windows 11 или Walker) нажатием `Super + Ctrl + R`.

### 🖼️ Работа с обоями и темами (Super + Shift + T)
Специальный bash-скрипт генерирует меню выбора с превью-миниатюрами:
- Опция "Themes" автоматически извлекает фоновую картинку темы Omarchy и показывает её рядом с названием.
- Опция "Wallpapers" показывает сетку из всех картинок в `~/Wallpapers`. При выборе вызывает `omarchy-lutgen-wallpapers`, перекрашивая систему под выбранную картинку и применяя её как фон через `swaybg`.
