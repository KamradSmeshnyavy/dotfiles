# WezTerm

Краткое описание: Мощный, кроссплатформенный эмулятор терминала с поддержкой мультиплексирования.

## Пути
- **Исходники в репозитории:** apps/wezterm
- **Линкуется в:** ~/.config/wezterm

## Отличия от дефолтной конфигурации и добавленные фичи
- **Цветовая схема и шрифты:** Используется тема "Catppuccin Mocha". Шрифты вынесены в модуль `config.fonts`, используется fallback на шрифт `Maple Hand` для элементов интерфейса, таких как заголовки окон.
- **Производительность:** Настроено использование движка `WebGpu` с профилем `HighPerformance` и ограничением кадров `animation_fps = 60`, `max_fps = 60` для плавной работы.
- **Интерфейс (UI):** 
  - Включена панель вкладок, которая располагается снизу (`tab_bar_at_bottom = true`). Отключен скроллбар (`enable_scroll_bar = false`).
  - Минимальные отступы внутри окна (`window_padding` настроены на комфортное использование: top: 12, bottom: 7, left/right: 3).
  - Скрыто предупреждение при закрытии окна (`window_close_confirmation = 'NeverPrompt'`).
  - Интегрирован плагин `tabline` для кастомизации верхней панели в стиле Catppuccin.
- **Кастомный курсор:** Используется мигающее подчеркивание (`BlinkingUnderline`) с плавными анимациями (`EaseIn`/`EaseOut`) и увеличенной толщиной `4`.
- **Модульная структура:** Конфигурация элегантно разбита на отдельные lua-модули (`appearance.lua`, `bindings.lua`, `domains.lua`, `fonts.lua`, `general.lua`, `launch.lua`).
- **Хоткеи (кастомный биндинг):**
  - `CTRL + p` - Command Palette
  - `SUPER/ALT + p` - Tab Navigator
  - `CTRL + w` (и `W`) - закрытие текущей вкладки без подтверждения
  - `ALT + a / d` - переключение между вкладками
  - `SUPER/ALT + \` - вертикальный сплит панелей
  - Настройка клавиши-модификатора (`SUPER` или `ALT`) автоматически адаптируется под операционную систему (MacOS или Windows) с помощью кастомного модуля `utils.platform`.
