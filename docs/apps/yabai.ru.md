# Yabai

Краткое описание: Оконный менеджер для macOS (использовался до/вместе с aerospace).

## Пути
- **Исходники в репозитории:** `apps/yabai`
- **Линкуется в:** `~/.config/yabai` (только на macOS)

## Отличия от дефолтной конфигурации и добавленные фичи

1. **Загрузка Scripting Addition (SA):**
   - Использует `sudo yabai --load-sa` для загрузки расширенных функций.
   - Автоматически перезагружает SA при перезапуске Dock (`dock_did_restart`).

2. **Отображение и Layout:**
   - Дефолтный layout — `bsp` (Binary Space Partitioning).
   - Зарезервировано место для внешнего бара (например, Sketchybar): `all:40:0`.
   - Включена прозрачность: активные окна непрозрачны (`1.0`), неактивные — прозрачны (`0.8`), продолжительность анимации смены прозрачности — `0.0`.
   - Тени включены только для плавающих окон (`window_shadow float`).
   - Отключены анимации окон (`window_animation_duration 0.0`).
   - Отступы (gaps): `10` между окнами, `8` от краев экрана.

3. **Поведение и мышь:**
   - Мышь следует за фокусом (`mouse_follows_focus on`).
   - Фокус следует за мышью (`focus_follows_mouse autoraise`).
   - Модификатор мыши — `cmd`. Левая кнопка двигает окно, правая изменяет размер, при перетаскивании окна меняются местами (`swap`).
   - Новые окна появляются как "второй ребенок" (`window_placement second_child`).

4. **Правила для приложений (Rules):**
   - Большой список приложений исключен из тайлинга (`manage=off`): `AmneziaVPN`, `Ghidra`, `Terminal`, `LuLu`, `Calculator`, `System Settings`, `VLC`, диалоги Finder и Safari, `Activity Monitor` и другие.
   - Жесткая привязка окон к рабочим столам:
     - `Zen` -> workspace 2
     - `Telegram`, `Spotify` -> workspace 3
     - `Code` -> workspace 4
     - `Ghidra` -> workspace 5
