# Ghidra

Краткое описание: Пользовательская тема оформления для реверс-инжиниринг фреймворка Ghidra.

## Пути
- **Исходники в репозитории:** `apps/ghidra`
- **Линкуется в:** Файл `ghidra.theme` является символической ссылкой на `omarchy-themes/black-ice/theme/SAGA-Ghidra-update.theme`. Применение в самой Ghidra происходит через настройки импорта тем интерфейса.

## Отличия от дефолтной конфигурации и добавленные фичи

1. **Базовое оформление:**
   - Название темы: `SAGA`.
   - Основана на профиле (Look and Feel): `Flat Dark`.
   - Принудительно включены темные цвета по умолчанию (`useDarkDefaults = true`).

2. **Кастомизация инструментов (Цветовая палитра):**
   - **Декомпилятор (Decompiler):** Настроены цвета для выделения переменных (полупрозрачный желтый), поиска, путей, source/sink узлов.
   - **ByteViewer (Hex-редактор):** Кастомные цвета подсветки выделения (`#bfbf40`) и клика средней кнопкой мыши.
   - **Code Compare (Сравнение кода):** Разные цвета для совпадающих (`#994399`), несовпадающих (`#9775ff`) участков и других отличий.
   - **Текущая строка (Current Line):** Выделяется темным оттенком `#11181d`.
   - Настроены цвета графов P-кода в декомпиляторе (вершины, ребра, константы, регистры).
