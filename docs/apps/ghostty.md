# Ghostty

Краткое описание: Конфигурация для быстрого кроссплатформенного эмулятора терминала Ghostty, использующего нативный UI и ускорение GPU.

## Пути
- **Исходники в репозитории:** `apps/ghostty`
- **Линкуется в:** `~/.config/ghostty`

## Отличия от дефолтной конфигурации и добавленные фичи
Конфиг делает упор на удобство работы с буфером обмена, кастомную типографику и интеграцию внешних шейдеров/скриптов.

### ✒️ Внешний вид и Шрифты
- **Шрифт:** Основной шрифт — `Maple Mono NF CN` (размер 12).
- Включены дополнительные фичи шрифтов (`font-feature`): `ss01` (лигатуры для `!=`, `===`), `ss02` (`<=`, `>=`), `ss03` (`->`), `ss04` (`</>`).
- **Темы:** Поддержка светлых/темных тем (например, переключение на Catppuccin Mocha / TokyoNight), но в данный момент подтягивается внешняя тема `theme.conf` (интеграция с Omarchy).
- Поддерживаются кастомные шейдеры (папки `my_shaders/`, `my_shaders_new/`).

### ⚙️ Интеграции и Поведение
- **Буфер обмена:** Включено разрешение на чтение и запись (`clipboard-read = allow`, `clipboard-write = allow`), работает `copy-on-select = true` для мгновенного копирования текста при выделении.
- **Окна:** Терминал запоминает состояние окна (`window-save-state = always`), отключено подтверждение при закрытии вкладок.
- Присутствует скрипт `start-tmux.sh` для быстрого проброса терминала в Tmux-сессию.
