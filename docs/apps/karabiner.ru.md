# Karabiner

Краткое описание: Инструмент для глубокой кастомизации клавиатуры на macOS (Karabiner-Elements).

## Пути
- **Исходники в репозитории:** `apps/karabiner`
- **Линкуется в:** `~/.config/karabiner` (только на macOS)

## Отличия от дефолтной конфигурации и добавленные фичи

Были добавлены следующие правила (Complex Modifications):

1. **Vim-подобная навигация:**
   - `Left Ctrl + h/j/k/l` заменены на стрелки.
   - `Right Command + h/j/k/l` заменены на стрелки.

2. **Программистский слой (AltGr):**
   - Нажатие `Right Option` переопределяет другие клавиши (Q, W, E, R, T, Y, U, I, O, P и др.) для ввода специальных символов, которые часто используются при программировании.

3. **Глобальный Vim-режим (11 компонентов):**
   - Полная эмуляция базовых команд Vim на уровне системы.
   - Визуальный режим: выделение текста с помощью `h, j, k, l, e, b, 0, ^, $, gg, G, {, }` и последующее удаление/копирование (`d, y, c, x`).
   - Операторы: `dd`, `yy`, `cc` и их комбинации с движениями (`de, db, d0, d$, dgg` и др.).
   - Редактирование: `x, X, p, P, u, control+r` (undo/redo).
   - Навигация: `h, j, k, l` с поддержкой модификаторов.
   - Переход в режим вставки (отключение Vim-режима): `i, I, a, A, o, O`.
   - Интеграция с Hammerspoon: клавиши `s`, `m`, `spacebar` вызывают кастомные модальные окна.
   - Отключение неиспользуемых клавиш в командном режиме.
   - Автоматический выход из режима при прикосновении к трекпаду (finger on trackpad + any key -> off).

4. **Дополнительные системные модификации:**
   - **Right Command** работает как `Escape`, если нажать и отпустить быстро, и как обычный `Command`, если удерживать.
   - `Right Command + Backspace` эмулирует клавишу `Delete` (удаление вперед).
   - **Enhanced CapsLock:** расширенные возможности для CapsLock (часто используется как Hyper/Ctrl/Esc).
