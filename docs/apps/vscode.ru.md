# VS Code

[🇬🇧 English](vscode.md)

Конфигурация Visual Studio Code: шрифты, тема, сниппеты, горячие клавиши и настройки.

## Пути

- **В репозитории:** `apps/vscode`
- **Линкуется в:**
  - Linux: `~/.config/Code/User/` (settings.json, keybindings.json, snippets)
  - macOS: `~/Library/Application Support/Code/User/` (те же файлы)
  - `~/.config/vscode/markdown-preview-enhanced` (конфиг Markdown Preview Enhanced)

## Отличия от настроек по умолчанию

1. **Тема и оформление**
   - Цветовая тема следует Omarchy (`omarchy-theme-set-vscode` пишет `workbench.colorTheme` при каждой смене темы).
   - Иконки файлов: `catppuccin noctis icons`; иконки интерфейса: `fluent-icons`.
   - Свои цвета курсора, направляющих отступов и токенов Markdown (жирный, подчёркивание ссылок, цвет списков).
   - Свой CSS для интерфейса (скриншоты — `assets/vsc_*.webp`).

2. **Шрифты и редактор**
   - Шрифт редактора: **Maple Mono NF CN** с длинным списком запасных, лигатуры включены, размер 16. Профиль шрифтов
     (`omarchy-font-profile`) меняет первую гарнитуру и размеры.
   - Относительные номера строк, форматирование при вставке / сохранении / наборе.
   - Без мини-карты и навигационной панели; курсор-блок с плавным миганием.

3. **Встроенный терминал**
   - Оболочка по умолчанию: `zsh` (macOS), `nu` (Windows); картинки в терминале; копирование при выделении.

4. **Горячие клавиши (keybindings.json)** — Vim-подобные операции с файлами в Explorer (когда фокус не в поле ввода):
   `c` / `shift+c` — скопировать абсолютный / относительный путь, `x` — вырезать, `y` — копировать, `p` / `v` —
   вставить, `q` — фокус на редактор.

5. **Сниппеты и ассоциации** — сниппеты для `c`, `java`, `json`, `jsonc`, `markdown`, `mdx`, `nushell`, `python`
   (`snippets/`); ассоциации файлов (`*.copilotmd`, `{hexdiff}`, `*.png` и `*.pdf` открываются нужными расширениями).

## Git и локальные значения

`settings.json` отслеживается, но ключи шрифта, размера и цветовой темы меняются при каждой смене профиля шрифтов или
темы. Git clean-фильтр `scripts/git-filters/vscode-local` (настраивает `just link`, см. `.gitattributes`) кладёт в
индекс канонические значения, поэтому эти переключения не дают диффа. Поменять их в репо — правкой `CANON` в фильтре.
