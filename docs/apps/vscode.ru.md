# VSCode

Краткое описание: Конфигурация редактора Visual Studio Code (шрифты, темы, сниппеты, горячие клавиши и настройки).

## Пути
- **Исходники в репозитории:** `apps/vscode`
- **Линкуется в:**
  - macOS: `~/Library/Application Support/Code/User/` (settings.json, keybindings.json, snippets)
  - Linux: `~/.config/Code/User/` (settings.json, keybindings.json, snippets)
  - Специфично: `~/.config/vscode/markdown-preview-enhanced` (конфиг для плагина Markdown Preview Enhanced).

## Отличия от дефолтной конфигурации и добавленные фичи

1. **Темы и оформление:**
   - Основная тема: `Pastel Hacker`.
   - Альтернативные (preferred): `Dobri Next -A01- Dark` (темная), `Rosé Pine Dawn` (светлая).
   - Тема иконок файлов: `catppuccin noctis icons`.
   - Тема иконок интерфейса: `fluent-icons`.
   - Кастомизация цветов: изменены цвета курсора (`#b4befe`), направляющих отступов (`#F5C2E7`), а также токенов Markdown (жирный шрифт, подчеркивание ссылок, цвет списков).

2. **Шрифты и редактор:**
   - Шрифт редактора: `Maple Mono NF` (и большой стек запасных шрифтов). Включены лигатуры.
   - Размер шрифта: `16`.
   - Относительные номера строк (`relative`).
   - Автосохранение/Автоформатирование: формат при вставке, сохранении, наборе (`formatOnPaste`, `formatOnSave`, `formatOnType`).
   - Отключены мини-карта (`minimap.enabled: false`) и навигационная панель интерфейса (`workbench.navigationControl.enabled: false`).
   - Курсор в виде блока (`block`) со сглаженной анимацией мерцания.

3. **Интегрированный терминал:**
   - Оболочка по умолчанию: `zsh` (macOS), `nu` (Windows).
   - Шрифт терминала: `MesloLGS NF`.
   - Включена поддержка изображений в терминале (`enableImages: true`).
   - Автоматическое копирование при выделении (`copyOnSelection`).

4. **Горячие клавиши (keybindings.json):**
   - Добавлена **Vim-подобная навигация и файловые операции** в проводнике (Explorer). Без фокуса на поле ввода используются клавиши:
     - `c` / `shift+c`: Скопировать абсолютный/относительный путь.
     - `x`: Вырезать (Cut).
     - `y`: Копировать (Copy).
     - `p` / `v`: Вставить (Paste).
     - `q`: Переместить фокус на редактор.

5. **Сниппеты и ассоциации:**
   - Добавлен набор кастомных сниппетов для `c`, `java`, `json`, `jsonc`, `markdown`, `mdx`, `nushell`, `python` (папка `snippets`).
   - Настроены ассоциации для форматов (например, `*.copilotmd`, `{hexdiff}`, `*.png` и `*.pdf` открываются через соответствующие плагины).
