# Kanata

Краткое описание: Кроссплатформенный программный перехватчик и ремаппер клавиатуры (аналог KMonad/Karabiner).

## Пути
- **Исходники в репозитории:** `apps/kanata`
- **Линкуется в:** Настраивается индивидуально для ОС (через systemd/launchd, не прописано в основном `install.conf.yaml`).

## Отличия от дефолтной конфигурации и добавленные фичи

В конфигурации определено три слоя (Layers):

1. **Базовый слой (base):**
   - **Tab (tab-mod):** При быстром нажатии (tap) работает как обычный `Tab`. При удержании (hold) активирует слой стрелок (`arrow-layer`).
   - **Правый Alt / AltGr (alt-symbols):** При быстром нажатии работает как `Esc`. При удержании активирует слой программистских символов (`symbols-layer`).
   - `Caps Lock` переназначен на `Left Ctrl`.

2. **Слой навигации (arrow-layer):**
   - Активируется удержанием `Tab`.
   - Навигация в стиле Vim: `h, j, k, l` работают как стрелки `Left, Down, Up, Right`.
   - Дополнительные клавиши: `u` -> Backspace, `i` -> Delete, `m` -> Enter (Ret).
   - Правый Alt (в этом слое) переназначен на `Delete`.

3. **Слой символов (symbols-layer):**
   - Активируется удержанием правого `Alt`.
   - Предназначен для ввода символов без увода рук с основного ряда.
   - **Верхний ряд (QWERTY):** вводит `@ ( ) [ ] { } < > = | ~`.
   - **Средний ряд (ASDFGH):** вводит `# $ % ^ & * - _ + : "`.
   - **Нижний ряд (ZXCVBN):** вводит `/ \ ? ! |`, а также `Enter`, `Backspace`.
   - **Макросы:** на нижнем ряду также реализованы макросы для ввода часто используемых конструкций в коде:
     - `,` -> `->`
     - `.` -> `0x`
     - `/` -> `!=`
