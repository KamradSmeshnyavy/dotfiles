# Kitty

Краткое описание: Быстрый, GPU-ускоренный эмулятор терминала.

## Пути
- **Исходники в репозитории:** `apps/kitty`
- **Линкуется в:** `~/.config/kitty`

## Отличия от дефолтной конфигурации и добавленные фичи
Мощная конфигурация с акцентом на типографику и тесную интеграцию с Neovim и системой тем Omarchy.

### ✒️ Шрифты и Типографика
- **Шрифт:** `Maple Mono NF CN` (размер 12.0).
- Включены продвинутые фичи шрифта (`font_features +cv01 +ss02 +ss04 +ss05 +zero`) для лучшего отображения лигатур и символов (например, перечеркнутый ноль).
- Добавлен стильный след за курсором (`cursor_trail 3`).

### 🤝 Интеграция с Neovim (kitty-scrollback)
Реализована мощная интеграция для просмотра истории терминала прямо в Neovim:
- `ALT + P`: Открыть весь буфер прокрутки в Neovim.
- `SUPER + SHIFT + P`: Открыть только вывод последней выполненной команды.
- `CTRL + SHIFT + Right Click`: Клик по выводу команды откроет его в Nvim.

### 🎨 Внешний вид и Окна
- Полупрозрачный фон (`opacity 0.95`) с сильным размытием (`background_blur 64`).
- Скрытие декораций окна (`hide_window_decorations titlebar-only`).
- **Темы:** Конфиг автоматически подтягивает цвета из глобальной темы `Omarchy` через симлинк `include theme.conf`.

### ⚙️ Системные твики
- **Remote Control:** Разрешен (`socket-only`) для взаимодействия скриптов (включая neovim-kitten) с терминалом по сокету.
- **macOS специфичные настройки:** Опция Option работает как Alt (`macos_option_as_alt`), панель заголовка сливается с фоном, правильный биндинг слов (`alt+left`/`right`).
