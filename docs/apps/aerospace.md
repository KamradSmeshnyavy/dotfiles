# Aerospace

Краткое описание: Оконный менеджер (tiling window manager) для macOS, используемый как замена yabai.

## Пути
- **Исходники в репозитории:** `apps/aerospace`
- **Линкуется в:** `~/.config/aerospace` (только на macOS)

## Отличия от дефолтной конфигурации и добавленные фичи

1. **Интеграции:**
   - Триггерит событие в `sketchybar` при смене рабочего стола (`aerospace_workspace_change`), передавая `FOCUSED_WORKSPACE`.
   - Интеграция с `borders` (рисует рамки вокруг активных и неактивных окон). Цвет активного: `#ffe1e3e4`, неактивного: `#ff494d64`, толщина: `5.0`.
   - Триггерит переключение отступов (gaps) через `sketchybar`.

2. **Отображение и поведение:**
   - Менеджер автоматически стартует при логине.
   - Заданы внутренние и внешние отступы между окнами и краями экрана (gaps): `10` между окнами, `8` от краев.
   - Дефолтный layout — `tiles`, ориентация — `auto` (горизонтальная для широких экранов, вертикальная для высоких). 
   - Нормализация контейнеров (`flatten-containers`, `opposite-orientation-for-nested-containers`).
   - Отступ для аккордеон-контейнеров (accordion-padding) равен `300`.
   - Мышь перемещается на активный монитор (`move-mouse monitor-lazy-center`).

3. **Правила для окон (floating-правила и воркспейсы):**
   - Заданы правила для плавающих окон (floating mode). Среди них нативные приложения macOS, браузеры, настройки и т.п.
   - Перенесены правила из yabai: `finder`, `safari`, `camera`, `discord`, `mail`, `obsidian`, `terminal`, `ghidra`, `vlc` и другие приложения по умолчанию открываются в плавающем режиме, а также диалоговые окна `finder`, `safari settings`, диалоги сохранения.
   - Некоторые приложения жестко привязаны к воркспейсам:
     - `zen` -> 2
     - `telegram`, `spotify` -> 3
     - `code` -> 4
     - `ghidra` -> 5

4. **Горячие клавиши (Qwerty-пресет):**
   - **Управление фокусом:** `alt-h/j/k/l` (vim-стиль), `alt-tab/shift-tab` для навигации DFS, `alt-semicolon/quote` для перехода к крайним окнам.
   - **Перемещение окон:** `alt-shift-h/j/k/l`.
   - **Воркспейсы:** `alt-1...6` для перехода, `alt-shift-1...6` для перемещения текущего окна на воркспейс.
   - **Float и Fullscreen:** `alt-space` (tiling/floating), `alt-shift-f` и `alt-f` (fullscreen).
   - **Изменение размеров:** `alt-ctrl-h/j/k/l` (ресайз), `alt-ctrl-e` (balance-sizes).
   - **Мониторы:** `alt-ctrl-d` (следующий монитор), `alt-ctrl-1...3` (фокус), `alt-ctrl-shift-n/p` (переместить на другой монитор).
   - **Моды (Binding Modes):** 
     - **Service Mode** (`alt-shift-semicolon`): сброс раскладки (`r`), переключение float (`f`), закрыть все кроме текущего (`backspace`), возврат назад (`esc`).
