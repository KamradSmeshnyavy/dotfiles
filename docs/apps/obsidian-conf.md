# Obsidian

Краткое описание: Конфигурационные файлы для Obsidian (настройки внешнего вида, горячие клавиши и CSS-сниппеты).

## Пути
- **Исходники в репозитории:** `apps/obsidian-conf`
- **Линкуется в:** Настраивается вручную (копируется в директорию `.obsidian/` нужного хранилища, т.к. не прописано в основном установщике).

## Отличия от дефолтной конфигурации и добавленные фичи

1. **Внешний вид (appearance.json):**
   - Используется тема: `AnuPpuccin`.
   - Акцентный цвет (Accent Color): `#89a2d7` (оттенок лавандового/голубого).
   - Базовый размер шрифта: `18`.
   - Скрыта боковая панель с иконками (Ribbon): `showRibbon: false`.
   - Включен кастомный CSS-сниппет: `obsidian.css`.

2. **Горячие клавиши (hotkeys.json):**
   - **Интерфейс:**
     - Переключение левой/правой боковых панелей: `Mod + E` / `Alt + E`.
     - Открытие графа: `Ctrl + Tab`.
     - Быстрый переход по файлам (Switcher): `Mod + P`.
     - Глобальный поиск: `Alt + S`.
   - **Навигация по вкладкам:**
     - Следующая/Предыдущая вкладка: `Alt + D` / `Alt + A`.
   - **Форматирование:**
     - Заголовки (H1-H6): `Mod + 1...6`.
     - Вставка блока кода: `Mod + Shift + K`.
     - Inline-код: `Mod + Shift + C`.
     - Математические блоки: `Alt + M` (inline) и `Mod + Shift + M` (math block).
     - Переключение режима предпросмотра Markdown: `Mod + Shift + V`.
   - **Редактор:**
     - Поиск и замена: `Mod + H`.
     - Перемещение строк вверх/вниз: `Alt + ArrowUp/ArrowDown`.
     - Добавление мульти-курсора выше/ниже: `Alt + Mod + ArrowUp/ArrowDown`.
