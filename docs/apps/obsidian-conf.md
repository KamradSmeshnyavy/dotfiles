# Obsidian

[🇷🇺 Русский](obsidian-conf.ru.md)

Obsidian config files: appearance, hotkeys and CSS snippets.

## Paths

- **In the repo:** `apps/obsidian-conf`
- **Linked to:** set up by hand (copied into the `.obsidian/` folder of a vault; not part of the installer).

## What differs from the defaults

1. **Appearance (appearance.json)**
   - Theme `AnuPpuccin`, accent colour `#89a2d7` (lavender blue), base font size 18.
   - The ribbon is hidden (`showRibbon: false`); the custom CSS snippet `obsidian.css` is on.

2. **Hotkeys (hotkeys.json)**
   - Interface: left / right sidebar — `Mod + E` / `Alt + E`; graph — `Ctrl + Tab`; switcher — `Mod + P`; global
     search — `Alt + S`.
   - Tabs: next / previous — `Alt + D` / `Alt + A`.
   - Formatting: headings H1–H6 — `Mod + 1…6`; code block — `Mod + Shift + K`; inline code — `Mod + Shift + C`; math —
     `Alt + M` (inline) and `Mod + Shift + M` (block); toggle Markdown preview — `Mod + Shift + V`.
   - Editor: search and replace — `Mod + H`; move line up / down — `Alt + ↑/↓`; add a cursor above / below —
     `Alt + Mod + ↑/↓`.
