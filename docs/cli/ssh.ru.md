# SSH

Краткое описание: Клиент безопасного удаленного доступа по протоколу SSH.

## Пути
- **Исходники в репозитории:** `cli/ssh`
- **Линкуется в:** `~/.ssh`

## Отличия от дефолтной конфигурации и добавленные фичи
- Глобальные настройки (`Host *`) оптимизированы:
  - Пробрасываются языковые переменные окружения (`LANG`, `LC_*`).
  - Включен проброс SSH-агента (`ForwardAgent yes`).
  - Отключен проброс X11 (`ForwardX11 no`).
  - Заданы интервалы поддержки сессии: `ServerAliveInterval 15` и таймаут подключения `ConnectTimeout 20`.
- Настроен алиас для хоста `bastion` с предустановленным ключом `id_rsa`, пользователем `ec2-user` и конкретным адресом.
