# Todo (Theme scripts & patches)

Краткое описание: Набор системных утилит и скриптов для управления конфигурацией системы и темами оформления (например, в рамках Omarchy).

## Пути
- **Исходники в репозитории:** `cli/todo`
- **Линкуется в:** `~/.config/todo`

## Отличия от дефолтной конфигурации и добавленные фичи
- Содержит bash-скрипт `theme.sh` для глобального переключения цветовых тем (профили `current` и `catppuccin-mocha-pink`). Скрипт синхронно обновляет:
  - Конфигурации терминалов и панелей (Sketchybar, Ghostty, Zellij, tmux).
  - Темы редакторов (VS Code, Neovim/nixvim).
  - Стили шелла (Starship).
  - Цветовые схемы утилит (например, подмена файла `theme.yml` для Eza).
- Хранит отладочные diff-патчи конфигурации NixOS/Darwin (например, `nvim-rollback`), используемые для быстрого возврата к предыдущим состояниям системы.
