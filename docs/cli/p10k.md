# P10k

Краткое описание: Конфигурация для p10k.

## Пути
- **Исходники в репозитории:** `cli/p10k`
- **Линкуется в:** `Unknown (Not in install.conf.yaml, might use stow)`

## Отличия от дефолтной конфигурации и добавленные фичи
- Включает кастомные настройки, оптимизированные под общий стиль системы Omarchy и улучшающие базовый пользовательский опыт (шорткаты, цвета, интеграция с другими утилитами).
