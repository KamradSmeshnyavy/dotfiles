# Tig

[🇷🇺 Русский](tig.ru.md)

A text-mode git interface, great for browsing history (lazygit opens it with `t`).

## Paths

- **In the repo:** `tui/tig`
- **Linked to:** `~/.config/tig`

## What differs from the defaults

- Git's own colours off (`set git-colors = no`); white on black with accents.
- Cursor green, search results yellow, line numbers red.
- Diffs: headers yellow, indexes blue, hunks magenta.
