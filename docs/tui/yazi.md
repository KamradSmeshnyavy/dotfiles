# Yazi

Краткое описание: Невероятно быстрый консольный файловый менеджер на Rust с асинхронным вводом-выводом и превью.

## Пути
- **Исходники в репозитории:** `tui/yazi`
- **Линкуется в:** `~/.config/yazi`

## Отличия от дефолтной конфигурации и добавленные фичи
Конфигурация Yazi сильно расширена за счет системы плагинов и кастомных скриптов (`init.lua`).

### 🔌 Плагины (через package.toml)
Подключено большое количество полезных модулей:
- **Интеграция с системами:** `git` / `vcs-files` для отображения статуса файлов, `mactag` для поддержки macOS тегов.
- **Внешний вид:** `full-border` для отрисовки полных рамок, `max-preview` для максимизации окна предпросмотра.
- **Удобство использования:**
  - `smart-enter` — умный вход в директории/файлы.
  - `chmod` — изменение прав доступа прямо из TUI.
  - `clipboard` — интеграция с системным буфером обмена.
  - `mount` — для управления примонтированными дисками.
  - `ouch` — плагин для работы с архивами любых форматов прямо из Yazi.
- Интеграция с нечетким поиском `television`.

### 🎨 Темизация и UI
- Используется кастомная статус-барная панель, написанная на Lua (`init.lua`), с отображением прогресса загрузки и метаданных.
- Подключена цветовая схема **Catppuccin Mocha** (через flavor). В `theme.toml` прописаны детальные настройки цветов, иконок для файлов и подсветки синтаксиса.

### ⌨️ Хоткеи (keymap.toml)
Присутствует массивный файл биндингов, адаптирующих Yazi под стиль Vim-навигации и предоставляющих быстрый доступ к подключенным плагинам (архивация, поиск, работа с git).
