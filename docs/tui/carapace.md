# Carapace

Краткое описание: Мульти-шелловый парсер автодополнений для терминала (bridge completions).

## Пути
- **Исходники в репозитории:** `tui/carapace`
- **Линкуется в:** `~/.config/carapace`

## Отличия от дефолтной конфигурации и добавленные фичи
- **Связующие автодополнения (Bridges):**
  - Создан файл `bridges.yaml`, в котором настроен мост для получения автодополнений из оболочки `fish`.
  - Применено к популярным утилитам, у которых могут отсутствовать нативные дополнения в других оболочках: `atuin`, `brew`, `bun`, `caffeinate`, `dust`, `ffmpeg`, `ffprobe`, `jq`, `kill`, `lsof`, `mpc`, `pip`, `pip3`, `tmux`, `uv`, `zellij`.
