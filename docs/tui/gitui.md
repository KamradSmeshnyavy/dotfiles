# GitUI

[🇷🇺 Русский](gitui.ru.md)

A fast git TUI written in Rust.

## Paths

- **In the repo:** `tui/gitui`
- **Linked to:** `~/.config/gitui`

## What differs from the defaults

- **Colours follow the Omarchy theme:** `theme.ron` is a theme slot — a gitignored symlink that `omarchy-app-themes` points at the current theme (see `omarchy-themes/APP-THEMING.md`). Change colours inside the theme, not here.
