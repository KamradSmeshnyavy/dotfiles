# Git

Краткое описание: Распределенная система управления версиями. 

## Пути
- **Исходники в репозитории:** `tui/git`
- **Линкуется в:** `~/.config/git`

## Отличия от дефолтной конфигурации и добавленные фичи
- Глобальный `.gitignore` подключен по пути `~/.config/git/.gitignore`.
- В качестве пейджера (`pager`) используется утилита `delta`.
- Редактором по умолчанию для коммитов (`core.editor`) и инструментом для слияния (`merge.tool`) выступает `nvim`.
- Используется стиль отображения конфликтов `zdiff3`.
- Подключен и настроен `git-lfs` для работы с бинарными и объемными файлами.
- Удобные алиасы для URL: `gh:` заменяет `git@github.com:`, `ghh:` заменяет `https://github.com/`, а `my:` заменяет `git@github.com:KamradSmeshnyavy /`.
- Включены опции безопасности (`safe.directory = *`), `push.autoSetupRemote = true` и дефолтная ветка `main`.
