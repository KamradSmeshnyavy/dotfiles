# Rmpc

Краткое описание: Красивый и современный консольный клиент для Music Player Daemon (MPD), написанный на Rust.

## Пути
- **Исходники в репозитории:** `tui/rmpc`
- **Линкуется в:** `~/.config/rmpc`

## Отличия от дефолтной конфигурации и добавленные фичи
- **Подключение и Интеграция:**
  - Подключается к локальному MPD (`127.0.0.1:6600`).
  - Тексты песен ищутся в папке `~/Music/CloudMusic`.
- **Внешний вид и Тема:**
  - Используется кастомная тема: `catppuccin_mocha` (темы хранятся в папке `themes`).
  - Максимальная частота кадров интерфейса ограничена 30 FPS.
  - Поддержка управления мышью включена.
  - Обложки альбомов (Album Art) ищутся автоматически, отображаются по центру с максимальным размером 1200x1200px (протоколы http/https отключены для обложек).
- **Интеграция с Cava:**
  - Встроена конфигурация аудио-визуализатора Cava с высокой частотой обновления (80 FPS).
  - Чувствительность установлена на 100, нижний порог частоты 50 Гц.
  - Данные для спектрограммы читаются из `/tmp/mpd.fifo` (предоставляемого MPD).
  - Настроено сглаживание: подавление шума 77, режимы monstercat и waves отключены.
- **Управление:**
  - Шаг изменения громкости: 5%.
  - Включена горячая перезагрузка конфигурации (`enable_config_hot_reload: true`).
