# Btop

[🇷🇺 Русский](btop.ru.md)

A terminal resource monitor (CPU, memory, disks, network, processes).

## Paths

- **In the repo:** `tui/btop`
- **Linked to:** `~/.config/btop`

## What differs from the defaults

- **Look:** `color_theme = "btop.theme"` (the current Omarchy theme), rounded corners, `braille` graphs, no theme
  background.
- **Panels:** only CPU and processes (`shown_boxes = "cpu proc"`).
- **Processes:** sorted by name, tree view, gradient colours.
- **Controls:** Vim keys (`vim_keys = true`), refresh every 2 s.
