# Svim

Краткое описание: Утилита для интеграции модального редактирования в приложения macOS (перехватчик ввода).

## Пути
- **Исходники в репозитории:** `tui/svim`
- **Линкуется в:** Настраивается системно (отсутствует в автоматическом симлинке).

## Отличия от дефолтной конфигурации и добавленные фичи
- Используется кастомный хук `svim.sh`, который передает текущий режим (`MODE`) и командную строку (`CMDLINE`) в `sketchybar` для отображения статуса Vim-режима в системном баре.
- В файле `blacklist` прописан обширный список приложений (такие как терминалы kitty, Alacritty, WezTerm, редакторы MacVim, Neovide, Code, а также браузеры Google Chrome, Arc, Firefox), в которых `svim` принудительно отключается, чтобы избежать конфликта горячих клавиш.
