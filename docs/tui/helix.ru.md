# Helix

Краткое описание: Современный модальный текстовый редактор, вдохновленный Kakoune и Neovim.

## Пути
- **Исходники в репозитории:** `tui/helix`
- **Линкуется в:** `~/.config/helix`

## Отличия от дефолтной конфигурации и добавленные фичи
- Активирована цветовая тема `catppuccin_mocha` с поддержкой True Color.
- Включены относительные номера строк, подсветка курсорной строки и направляющие отступов.
- Кастомизирован `statusline`: слева показывается режим, спиннер и диагностика; по центру — имя файла и статус контроля версий.
- Добавлено отображение Inlay Hints для LSP.
- Существенно переработана раскладка в нормальном и режиме выделения:
  - Управление навигацией (`w`, `e`, `b`) переопределено для поведения, более похожего на Vim (без залипания выделения).
  - Настроены удобные шорткаты для работы с системным буфером обмена (копирование, удаление, вставка).
  - Кнопка `esc` используется для снятия всех выделений и мультикурсоров.
