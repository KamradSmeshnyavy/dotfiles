# Tmux

[🇬🇧 English](tmux.md)

Терминальный мультиплексор: сессии, окна и панели.

## Пути

- **В репозитории:** `tui/tmux`
- **Линкуется в:** `~/.config/tmux`

## Отличия от настроек по умолчанию

Тяжёлый, полностью переписанный конфиг, заточенный под удобство и общий вид системы.

### Основа

- Окна и панели нумеруются с `1`; `renumber-windows on`.
- True Color, в том числе overrides для Ghostty (`xterm-ghostty`).
- Полная поддержка мыши.
- Закрытие последней панели переключает на другую сессию, а не выходит из tmux (`detach-on-destroy off`).

### Бинды (`tmux.binds.conf`)

- Все стандартные бинды сброшены (`unbind-key -a`) и прописаны заново.
- Бесшовная навигация между панелями tmux и окнами Neovim (`C-h`, `C-j`, `C-k`, `C-l`, `vim-tmux-navigator`).
- Многие бинды навеяны Zellij (часть работает без префикса).

### Внешний вид

- Цвета следуют теме Omarchy: `omarchy-tmux-theme` пишет `om-theme.conf` при каждой смене темы, а `om-app-theme.conf` —
  слот темы.
- `scripts/` — помощники для статус-бара, сессий и буфера обмена; свой статус-бар с сессией, окнами и временем.
