# Procs

Краткое описание: Современная замена `ps` написанная на Rust.

## Пути
- **Исходники в репозитории:** `tui/procs`
- **Линкуется в:** `~/.config/procs`

## Отличия от дефолтной конфигурации и добавленные фичи
- **Кастомные столбцы (Columns):**
  - Подробный вывод по умолчанию включает: Pid, UsageCpu, UsageMem, VmSize, VmRss, Slot, CpuTime, StartTime, Command, TcpPort.
  - Каждая секция отделена разделителем `Separator`.
- **Внешний вид и стиль:**
  - Настроены цвета столбцов (например, `BrightYellow|Yellow` для PID, `BrightCyan|Cyan` для CpuTime и TcpPort, `BrightMagenta|Magenta` для StartTime).
  - Градиенты для статусов процессов и процентов использования (например, зеленый-желтый-красный для загрузки).
  - Настроены символы для древовидного просмотра (`tree_symbols = ["│", "─", "┬", "├", "└"]`).
- **Поиск:**
  - Числовой поиск настроен на точное совпадение (`Exact`).
  - Текстовый поиск ищет частичные совпадения (`Partial`).
  - Логика объединения: `And`.
- **Интеграция с Docker:**
  - Включен мониторинг контейнеров через сокет: `/var/run/docker.sock`.
