# Television

Краткое описание: Терминальный нечеткий искатель (fuzzy finder), оптимизированный для работы с текстом и файлами.

## Пути
- **Исходники в репозитории:** `tui/television`
- **Линкуется в:** `~/.config/television`

## Отличия от дефолтной конфигурации и добавленные фичи
- **Пользовательский интерфейс (UI):**
  - Поддержка Nerd Font иконок включена (`use_nerd_font_icons = true`).
  - Интерфейс занимает 100% экрана, ориентация `landscape`, панель ввода расположена сверху (`input_bar_position = "top"`).
  - Панель предпросмотра включена по умолчанию и занимает 50% размера с ползунком прокрутки (`scrollbar = true`).
  - Статус бар включен, панель помощи и удаленного контроля по умолчанию скрыты.
- **Общие настройки:**
  - Размер истории: 200 записей. Глобальная история отключена (история разделена по каналам).
  - Дефолтный канал установлен на `files`.
  - Частота обновления интерфейса: 50 тиков в секунду (`tick_rate = 50`).
- **Интеграция с оболочкой (Shell integration):**
  - Настроены шорткаты: `ctrl-t` для умного автодополнения и `ctrl-r` для поиска по истории команд.
  - Кастомные триггеры каналов:
    - При вводе `cd`, `ls`, `rmdir` и `z` открывается канал `dirs`.
    - Команды `cat`, `vim`, `nano`, `bat`, файловые манипуляции и архиваторы вызывают канал `files`.
    - Git команды перенаправляются в `git-diff`, `git-branch`, `git-log`, `git-repos`.
    - Управление процессами (`kill`, `procs`) направляется в канал `procs`.
    - `docker run` триггерит канал `docker-images`.
