# Lla

Краткое описание: Быстрая и кастомизируемая замена ls.

## Пути
- **Исходники в репозитории:** `tui/lla`
- **Линкуется в:** `~/.config/lla`

## Отличия от дефолтной конфигурации и добавленные фичи
- Метод сортировки по умолчанию — `name`, формат вывода — `default`.
- Иконки отключены по умолчанию (`show_icons = false`).
- Формат прав доступа настроен на символический (например, `-rw-r--r--`).
- Включена "натуральная" сортировка (числа в именах файлов обрабатываются логично, например, 2.txt идет перед 10.txt).
- В `fuzzy` поиске настроено игнорирование тяжеловесных папок, таких как `node_modules`, `target`, `.git`, `.idea` и `.vscode`.
- Для формата `long` настроен кастомный вывод столбцов: `permissions`, `size`, `modified`, `user`, `group`, `name` с форматом даты `%Y-%m-%d %H:%M`.
