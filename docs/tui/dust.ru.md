# Dust

Краткое описание: Инструмент для анализа использования дискового пространства, альтернатива `du`.

## Пути
- **Исходники в репозитории:** `tui/dust`
- **Линкуется в:** `~/.config/dust`

## Отличия от дефолтной конфигурации и добавленные фичи
- Включен реверсивный порядок вывода графа (`reverse = true`), благодаря чему самые тяжелые директории отображаются внизу для удобства чтения в терминале.
