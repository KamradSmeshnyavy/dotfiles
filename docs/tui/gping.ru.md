# Gping

Краткое описание: Интерактивный графический пинг (ping) для терминала.

## Пути
- **Исходники в репозитории:** `tui/gping`
- **Линкуется в:** Не требует конфигурационных файлов (только скрипты установки).

## Отличия от дефолтной конфигурации и добавленные фичи
- Утилита используется со стандартными настройками без переопределения конфигурации.
- В репозитории лежат инструкции по установке на Ubuntu (через `azlux` репозиторий) и заготовка для Windows.
