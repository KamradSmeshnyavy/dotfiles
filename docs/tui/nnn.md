# Nnn

[🇷🇺 Русский](nnn.ru.md)

A tiny, extremely fast terminal file manager (`n` in Zsh).

## Paths

- **In the repo:** `tui/nnn`
- **Linked to:** `~/.config/nnn`

## What differs from the defaults

- **Plugins:** about 60 plugin scripts, including `autojump`, KDE Connect / GSConnect, `dragdrop`, `preview-tui` and
  `preview-tabbed`, plus archive and image tools (`imgview`, `imgur`, `nuke`, `pdfread`, `wallpaper`).
- **Bookmarks:** the `finderbms` file.
