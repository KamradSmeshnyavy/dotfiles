# GitUI

[🇬🇧 English](gitui.md)

Быстрый TUI-клиент git на Rust.

## Пути

- **В репозитории:** `tui/gitui`
- **Линкуется в:** `~/.config/gitui`

## Отличия от настроек по умолчанию

- **Цвета следуют теме Omarchy:** `theme.ron` — слот темы, игнорируемый git симлинк, который `omarchy-app-themes`
  направляет на текущую тему (см. `omarchy-themes/APP-THEMING.md`). Цвета меняются в теме, а не здесь.
