# Scripts

[🇬🇧 English](scripts.md)

Небольшие вспомогательные скрипты для TUI-утилит.

## Пути

- **В репозитории:** `tui/scripts`
- **Линкуется:** используемые скрипты линкуются из `scripts/bin` в `~/.local/bin` (например, `yazi-fm-dbus.py`).

## Что внутри

- `yazi-fm-dbus.py` — D-Bus-сервис `org.freedesktop.FileManager1`: запросы «Показать в папке» из приложений открываются
  в Yazi.
