# MPD

Краткое описание: Music Player Daemon - серверная служба для воспроизведения аудио с поддержкой удаленного управления.

## Пути
- **Исходники в репозитории:** `tui/mpd`
- **Линкуется в:** `~/.config/mpd`

## Отличия от дефолтной конфигурации и добавленные фичи
- **Директории:**
  - Музыкальная библиотека расположена в `~/Music/CloudMusic`.
  - Плейлисты хранятся в `~/.config/mpd/playlists`.
- **Сеть:**
  - MPD слушает запросы локально: `127.0.0.1` на порту `6600`.
- **Вывод звука (Аудио выходы):**
  - **CoreAudio (OSX):** Настроен программный микшер для вывода звука на macOS.
  - **FIFO Pipe:** Создан вывод звука в пайп `/tmp/mpd.fifo` с форматом `44100:16:2` (без ресемплирования, с использованием mmap). Этот вывод используется визуализаторами вроде Cava и плеером RMPC для анализа спектра и вывода графики.
