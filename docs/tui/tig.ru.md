# Tig

Краткое описание: Текстовый интерфейс для git, отлично подходящий для просмотра истории.

## Пути
- **Исходники в репозитории:** `tui/tig`
- **Линкуется в:** `~/.config/tig`

## Отличия от дефолтной конфигурации и добавленные фичи
- Отключены стандартные цвета git (`set git-colors = no`).
- Цветовая схема полностью переопределена: используется белый текст на черном фоне с акцентными цветами.
- Цвета элементов: курсор подсвечивается зеленым, результаты поиска желтым, номера строк красным.
- Настроена кастомизированная расцветка для diff-файлов: заголовки - желтые, индексы - синие, блоки изменений - пурпурные.
