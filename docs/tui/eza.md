# Eza

[🇷🇺 Русский](eza.ru.md)

A modern `ls` replacement with colours and icons, written in Rust.

## Paths

- **In the repo:** `tui/eza`
- **Linked to:** `~/.config/eza`

## What differs from the defaults

- A custom colour scheme on the Catppuccin palette (`theme.yml`): files, directories, symlinks and permissions.
- Git status colours: new — green, modified — yellow, deleted — red.
