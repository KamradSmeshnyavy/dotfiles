# Btop

Краткое описание: Консольный монитор ресурсов (CPU, память, диски, сеть, процессы).

## Пути
- **Исходники в репозитории:** `tui/btop`
- **Линкуется в:** `~/.config/btop`

## Отличия от дефолтной конфигурации и добавленные фичи
- **Интерфейс:**
  - Используется кастомная тема (`color_theme = "btop.theme"`).
  - Скругленные углы включены (`rounded_corners = true`).
  - Символы для графиков установлены как `braille`.
  - Отключен фон у темы (`theme_background = false`).
- **Отображение панелей:**
  - Показываются только панели CPU и процессов (`shown_boxes = "cpu proc"`).
- **Процессы:**
  - Сортировка процессов по умолчанию: по имени (`proc_sorting = "name"`).
  - Включен режим отображения в виде дерева (`proc_tree = true`).
  - Градиентная раскраска процессов включена.
- **Управление:**
  - Активированы клавиши навигации Vim (`vim_keys = true`).
  - Обновление интерфейса каждые 2 секунды (`update_ms = 2000`).
