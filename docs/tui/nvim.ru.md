# Neovim (nvim)

Краткое описание: Мощный, расширяемый текстовый редактор. Конфигурация построена на базе `LazyVim` с множеством кастомных доработок и плагинов для эффективной разработки.

## Пути
- **Исходники в репозитории:** `tui/nvim`
- **Линкуется в:** `~/.config/nvim`

## Отличия от дефолтной конфигурации и добавленные фичи
Эта конфигурация глубоко кастомизирована под нужды разработчика. Основные отличия:

### 🚀 Ядро и Пакетный менеджер
- **LazyVim:** Используется как основа (предустановлены лучшие практики, автодополнения, LSP).
- **Пакетный менеджер:** `lazy.nvim`.

### 🎨 Внешний вид
- **Своя тема:** Написана полностью кастомная тема **"pastel-hacker"** (`colorscheme.lua`). Она использует спокойные, приглушенные цвета (`bg = "#0d0e1a"`, `primary = "#7dcea0"`) для комфортной работы.
- Отключен дефолтный фон для некоторых элементов, изменена подсветка синтаксиса и LSP-диагностики.

### 🔌 Ключевые плагины
- **ИИ-помощники:** 
  - `Copilot.lua` и `Copilot_Chat.lua` для интеграции с GitHub Copilot.
- **Файловые менеджеры:**
  - `neo-tree.nvim` (дефолтный для LazyVim).
  - `oil.nvim` для редактирования файловой системы как текста.
  - `yazi.lua` - интеграция терминального файлового менеджера Yazi.
- **Интеграция с терминалом и Tmux:**
  - `vim-tmux-navigator` для бесшовной навигации между панелями Tmux и окнами Neovim.
  - `kitty-scrollback.nvim` для чтения буфера прокрутки терминала Kitty прямо в Neovim.
- **Удобство редактирования:**
  - `multicursor.nvim` для мультикурсора.
  - `surround.lua` для быстрого изменения скобок и кавычек.
  - `nvim-colorizer.lua` для подсветки hex-кодов цветов.
  - `markdown.lua` и `render-markdown.lua` для красивого отображения Markdown прямо в редакторе.
- **Трекинг времени / Алгоритмы:**
  - `wakatime` для учета времени.
  - `leetcode.lua` для решения задач прямо из Neovim.

### 🛠 LSP и Линтеры
- **Python:** Настроены `basedpyright` и `ruff`.
- **FASM:** Кастомная настройка LSP и синтаксиса для ассемблера (`fasm-lsp.lua`, `fasm-syntax.lua`).

Конфигурация оптимизирована для быстрой работы, глубоко интегрирована с Tmux, Kitty и ИИ-инструментами.
