# Atuin

[🇬🇧 English](atuin.md)

Краткое описание: Замена истории команд оболочки, сохраняющая историю в SQLite с возможностью синхронизации.

## Пути
- **Исходники в репозитории:** `tui/atuin`
- **Линкуется в:** `~/.config/atuin`

## Отличия от дефолтной конфигурации и добавленные фичи
- **Синхронизация:**
  - Включена автоматическая синхронизация (`auto_sync = true`).
  - Используется официальный сервер API (`sync_address = "https://api.atuin.sh"`).
  - Частота синхронизации задана на 10 минут (`sync_frequency = "10m"`).
- **Интерфейс и Поиск:**
  - Механизм поиска установлен на `skim`.
  - Отключена проверка обновлений (`update_check = false`).
  - Автоматическое выполнение команды после выбора включено (`enter_accept = true`).
- **Темы:**
  - Настроена директория `themes` для кастомного внешнего вида.
- **Цвета следуют теме Omarchy:** `themes/omarchy.toml` — слот темы, игнорируемый git симлинк, который `omarchy-app-themes` направляет на
  текущую тему (см. `omarchy-themes/APP-THEMING.md`). Цвета меняются в теме, а не здесь.
