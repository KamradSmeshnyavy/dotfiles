# Tmux

Краткое описание: Мультиплексор терминалов, позволяющий управлять несколькими сессиями и окнами в одном окне терминала.

## Пути
- **Исходники в репозитории:** `tui/tmux`
- **Линкуется в:** `~/.config/tmux`

## Отличия от дефолтной конфигурации и добавленные фичи
Здесь представлена тяжеловесная, полностью переписанная конфигурация, ориентированная на удобство и интеграцию с визуальным стилем системы.

### ⚙️ Базовые настройки
- **Индексация:** Окна и панели начинаются с `1` (а не с `0`), включена автоматическая перенумерация окон (`renumber-windows on`).
- **Цвета и Терминал:** Настроена поддержка True Color (в том числе кастомные overrides для терминала Ghostty: `xterm-ghostty`).
- **Мышь:** Полная поддержка мыши (`set -g mouse on`).
- При закрытии последней панели сессии Tmux не закрывается, а переключается на другую (`detach-on-destroy off`).

### ⌨️ Кастомные шорткаты (tmux.binds.conf)
- **Полная очистка:** Дефолтные бинды сбрасываются (`unbind-key -a`), и все нужные комбинации прописаны с нуля, чтобы избежать конфликтов.
- **Интеграция с Nvim:** Настроена бесшовная навигация между панелями Tmux и окнами Neovim (плагин `vim-tmux-navigator` / кастомные скрипты `C-h`, `C-j`, `C-k`, `C-l`).
- Многие комбинации вдохновлены идеями из мультиплексора **Zellij** (присутствуют следы биндов без префикса).

### 🎨 Внешний вид и Плагины
- Внешний вид зависит от глобальной темы **Omarchy** (динамически подтягивает цвета из `om-theme.conf`).
- Присутствует папка `scripts/`, содержащая скрипты для управления статус-баром, сессиями, интеграции с системным буфером обмена.
- Настроен кастомный статус-бар с отображением текущей сессии, окон и времени.
