# Eza

Краткое описание: Современная замена `ls` с цветами и иконками, написанная на Rust.

## Пути
- **Исходники в репозитории:** `tui/eza`
- **Линкуется в:** `~/.config/eza`

## Отличия от дефолтной конфигурации и добавленные фичи
- Используется кастомная цветовая схема на базе палитры Catppuccin (`theme.yml`).
- Настроены специфические цвета для файлов, директорий, симлинков и прав доступа, что улучшает визуальное восприятие.
- Проработана подсветка для git-статусов: новые файлы выделяются зеленым, измененные - желтым, удаленные - красным.
- Цвета интегрированы с общим скриптом переключения тем, находящимся в `cli/todo/theme`.
