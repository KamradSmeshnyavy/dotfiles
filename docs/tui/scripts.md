# Scripts

[🇷🇺 Русский](scripts.ru.md)

Small helper scripts for TUI tools.

## Paths

- **In the repo:** `tui/scripts`
- **Linked to:** the scripts that are used are linked from `scripts/bin` into `~/.local/bin` (e.g.
  `yazi-fm-dbus.py`).

## What's inside

- `yazi-fm-dbus.py` — a D-Bus `org.freedesktop.FileManager1` service that opens "Show in folder" requests from apps in
  Yazi.
