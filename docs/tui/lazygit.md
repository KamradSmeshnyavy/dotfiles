# Lazygit

Краткое описание: Популярный TUI клиент для git с простым управлением и широким функционалом.

## Пути
- **Исходники в репозитории:** `tui/lazygit`
- **Линкуется в:** `~/.config/lazygit`

## Отличия от дефолтной конфигурации и добавленные фичи
- Включена поддержка Nerd Fonts (v3) и отображение иконок файлов.
- Для рендеринга diff-вывода используется `delta` с параметрами `--dark --paging=never`.
- Настроены удобные кастомные команды (`customCommands`):
  - **Conventional Commits**: По сочетанию `<c-v>` открывается интерактивное меню выбора типа коммита (feat, fix, chore и т.д.), scope и сообщения, формирующее правильный формат.
  - **Pull Requests**: По сочетанию `<c-r>` создается PR через GitHub CLI (`gh pr create --fill --web`).
  - **Tig**: По клавише `t` открывается `tig` для детального просмотра истории изменений выбранного файла.
- Копирование в буфер обмена выведено на клавишу `y`.
- В качестве редактора по умолчанию настроен `nvim`.
