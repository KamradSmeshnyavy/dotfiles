# Fastfetch

[🇬🇧 English](fastfetch.md)

Краткое описание: Высокопроизводительная утилита для вывода информации о системе.

## Пути
- **Исходники в репозитории:** `tui/fastfetch`
- **Линкуется в:** `~/.config/fastfetch`

## Отличия от дефолтной конфигурации и добавленные фичи
- **Весь `config.jsonc` — слот темы:** `omarchy-app-themes` направляет его на конфиг fastfetch текущей темы (или
  `omarchy-themes/app-defaults`), поэтому логотип, рамка и цвета меняются вместе с темой. Ниже — раскладка по умолчанию.
- **Логотип:**
  - Загружается кастомный ASCII-арт из файла `~/.config/fastfetch/preset/anime.txt`.
  - Настроены отступы вокруг логотипа.
- **Интерфейс:**
  - Разделитель между ключом и значением: `➜ `.
  - Форматирование информации заключено в кастомную рамку (┌── SYSTEM INFORMATION ──┐).
  - Заголовок изменен на `GnixAij`.
- **Модули вывода:**
  - Выводится расширенный набор информации: OS, Kernel, Packages, Shell, DE/WM (включая LM и тему), Terminal, Host, CPU, Disk, Memory, Swap, Uptime, Display, Sound, WiFi, Local IP.
  - У модулей заменены стандартные названия на названия с иконками (например, ` OS`, ` DE`, ` PC`).
  - Строго задана цветовая палитра для ключей: желтый (система), зеленый (графика), красный (железо), маджента (сеть/звук).
  - Внизу выводится палитра цветов в виде кружков.
