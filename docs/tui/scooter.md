# Scooter

[🇷🇺 Русский](scooter.ru.md)

An interactive find-and-replace tool with file previews.

## Paths

- **In the repo:** `tui/scooter`
- **Linked to:** `~/.config/scooter`

## What differs from the defaults

- Preview syntax theme Catppuccin Mocha; extra themes in `themes/`.
- Opening a result runs `nvim %file +%line` — straight to the line.
