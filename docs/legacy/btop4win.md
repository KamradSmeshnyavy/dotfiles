# Btop4Win

Краткое описание: Порт Btop для Windows систем.

## Пути
- **Исходники в репозитории:** `tui/btop4win`
- **Линкуется в:** Настраивается индивидуально в окружении Windows (вероятно через Scoop).

## Отличия от дефолтной конфигурации и добавленные фичи
- **Интерфейс:**
  - Тема загружается по абсолютному пути (через Scoop): `D:\envir_vars\scoop\apps\btop\current\themes\catppuccin_mocha.theme`.
  - Фон темы включен (`theme_background = True`).
  - Символы для графиков установлены как `braille`.
- **Отображение панелей:**
  - В отличие от Linux-версии, тут показываются все четыре основные панели: `cpu`, `proc`, `net`, `mem`.
  - Включено отображение видеокарты (`show_gpu = True`), для нижней части графика CPU выделен GPU.
- **Процессы:**
  - Сортировка процессов: `cpu lazy`.
  - Отображение дерева процессов отключено (`proc_tree = False`).
- **Управление:**
  - Vim-биндинги отключены (`vim_keys = False`).
  - Ускоренное обновление данных каждые 1.5 секунды (`update_ms = 1500`).
