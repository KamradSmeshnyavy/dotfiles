# bookmarks-sync

Сводит закладки Firefox, Helium и Chromium в одно дерево без дублей и записывает его во все три браузера.
Запуск: `bookmarks-sync` или `just bookmarks-sync`.

```sh
bookmarks-sync -n        # показать, что изменится, ничего не трогая
bookmarks-sync           # синхронизировать; запущенные браузеры закроет (спросит) и откроет снова
bookmarks-sync -y        # то же без вопроса
bookmarks-sync --reset   # забыть прошлую синхронизацию: только объединение, без удалений
```

## Слияние

- Папки взаимных импортов (`Imported From Firefox`, `Imported from Mozilla Firefox/toolbar/…`) срезаются,
  их содержимое ложится в обычные папки. Меню закладок Firefox сливается с панелью.
- Дубль — одинаковый URL после чистки `utm_*`, `fbclid`, `gclid`, `yclid`, токенов Cloudflare и лишних
  параметров поиска Google. Из нескольких папок остаётся самая глубокая.
- Состояние прошлой синхронизации лежит в `~/.local/state/bookmarks-sync/state.json`. Новая закладка
  добавляется везде. Удалённая хоть в одном браузере удаляется везде. Перенос и переименование
  берутся оттуда, где их сделали; при конфликте побеждает Firefox, потом Helium.
- Если удаляется больше 10 закладок и больше четверти, скрипт останавливается: скорее всего, один браузер
  прочитался пустым. Если удаление настоящее — `--allow-mass-delete`.
- В корне панели сначала папки из `PINNED` в скрипте (`work`, `study`, `relax`, `shopping`), затем
  закладки, затем остальные папки — так Surfingkeys показывает эти папки первыми.
- `about:`/`place:` остаются только в Firefox, `chrome://` — только в Chromium-браузерах. «Мобильные»
  закладки Firefox в Chromium лежат в «Других» (пустой мобильный корень там скрыт).

## Запись

- **Firefox**: headless-экземпляр рабочего профиля с Marionette (`MOZ_REMOTE_ALLOW_SYSTEM_ACCESS=1`),
  Places API. Так Firefox Sync получает нормальные удаления. Перед записью Firefox сам делает бэкап в
  `<профиль>/bookmarkbackups/` (восстановление — «Библиотека → Восстановить»).
- **Helium / Chromium**: копия профиля (`Local State` + файлы закладок), headless-браузер с одноразовым
  расширением (`chrome.bookmarks`), повторный запуск для проверки того, что легло на диск, и перенос
  файлов обратно. Helium хранит закладки в зашифрованном `EncryptedBookmarks2`, JSON `Bookmarks` у него
  устаревший — править его бесполезно. Старые файлы — в `~/.local/state/bookmarks-sync/backups/`.
