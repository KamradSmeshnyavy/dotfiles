Файлы:
- shaders/cursors/sparkle-trail.slang — сам шейдер
- shaders/cursors/sparkle-trail.pipeline — подключение
- в kitty.conf добавил закомментированную строку под остальными вариантами, твой текущий smear-blocks-cold-steel не трогал

Что он рисует:
1. Светящийся хвост вокруг стандартного шлейфа kitty. Он двигается так же, как твой шлейф
   (cursor_trail_decay 0.1 0.4).
2. Искры вдоль пути. Вылетают назад и в стороны от места, где прошла голова курсора. Замедляются,
   падают вниз и мерцают. Часть искр вспыхивает четырёхлучевыми звёздочками. Цвет остывает от белого
   до цвета курсора темы.
3. Взрыв искр в точке, где курсор остановился.

При наборе текста (сдвиг на одну клетку) искр немного, при длинных прыжках — полный поток. Цвет поумолчанию берётся из курсора текущей темы omarchy.

Включить: раскомментируй строку sparkle-trail.pipeline в kitty.conf, закомментируй текущий custom_shaders и перезапусти kitty. Оставь cursor_trail 1.

Настройка без правки шейдера, через var в .pipeline, например:
var int   SPARK_COUNT   = 60      # больше искр
var float SPARK_GRAVITY = -4      # искры всплывают вверх, а не падают
var float FLARE_CHANCE  = 0.6     # больше звёздочек
var bool  USE_CURSOR_COLOR = false
var float3 SPARK_COLOR  = float3(1.0, 0.55, 0.15)
Все параметры с диапазонами описаны в шапке .slang.

Ограничение: kitty передаёт шейдеру только последнее перемещение курсора. Поэтому при быстром наборе искры от предыдущей клавиши пропадают, когда начинается следующее движение. Хвост при этом не обрывается, он плавный.

Новая версия: sparkle-plus

- sparkle-plus.slang — сам шейдер
- sparkle-plus.pipeline — цвет курсора из темы
- sparkle-plus-custom.pipeline — свои два цвета (в примере rose-pine)
- sparkle-plus-rainbow.pipeline — радуга

Что добавилось к первой версии:
1. Хвост теперь с градиентом от головы к хвосту и мерцающими блёстками внутри.
2. Искры летят смазанными штрихами, как при выдержке на фото, а не точками.
3. Угольки — медленные огоньки, которые всплывают и покачиваются. Живут дольше искр.
4. Кольцо ударной волны с искрящимся краем расходится от точки, куда прыгнул курсор.
5. Вспышка вокруг курсора на каждое нажатие клавиши.
6. Аура после остановки: пульсирующее свечение и огоньки, которые кружат вокруг курсора и гаснут примерно за 3 секунды.

Любой эффект выключается в .pipeline строкой вроде var float RING_INTENSITY = 0. Полный список параметров — в шапке .slang.

Как поменять цвет — в .pipeline:
var int COLOR_MODE = 1        # 0 = курсор темы, 1 = свои цвета, 2 = радуга
var float3 PRIMARY_COLOR   = float3(0.92, 0.74, 0.73)   # голова и часть искр
var float3 SECONDARY_COLOR = float3(0.77, 0.65, 0.91)   # хвост и остальные искры
var float3 HOT_COLOR       = float3(1.0, 0.92, 0.75)    # цвет только что вылетевших искр
Цвета задаются как hex, делённый на 255: #ebbcba → float3(0.92, 0.74, 0.73).

Подключение в kitty.conf (cursor_trail 1 оставь):
custom_shaders ~/dotfiles/apps/kitty/shaders/cursors/sparkle-plus.pipeline

Файлы: sparkle-lite.slang и sparkle-lite.pipeline. Ещё дописал короткий раздел про неё в твой 
sparkle.md.

Эффекты:
- хвост с градиентом и блёстками;
- искры, часть со звёздочками;
- угольки;
- взрыв искр и кольцо ударной волны при длинном прыжке;
- звезда, которая вспыхивает на курсоре при остановке (новый эффект);
- вспышка вокруг курсора при наборе.

Убрана только аура с кружащими огоньками.

Почему она экономнее:
1. Анимация короче. Больше всего энергии уходит на то, сколько кадров рисуется. Шейдер считается для каждого пикселя окна в каждом кадре. У sparkle-plus из-за ауры анимация идёт 3.3 с после каждого движения, это около 66 кадров на одно нажатие клавиши. У lite она идёт 0.65 с, около 20 кадров при 30 fps.
2. Пиксели вдали от курсора отсекаются сразу. Одна проверка по прямоугольнику вокруг пути курсора возвращает их нетронутыми, а это почти всё окно.
3. Меньше работы на частицы. Искр 18+8 вместо 48+16, угольков 5 вместо 14. На каждую частицу один хэш вместо шести. Далёкие частицы отбрасываются до тяжёлых exp и sin. Нет смазанных штрихов и atan2.
4. При наборе текста почти ничего не рисуется. На сдвиг в одну клетку вылетает 3 искры, без кольца и угольков. Полный набор эффектов только на длинных прыжках.

Подключение:
custom_shaders ~/dotfiles/apps/kitty/shaders/cursors/sparkle/sparkle-lite.pipeline
Цвет меняется так же, как в sparkle-plus: COLOR_MODE, PRIMARY_COLOR, SECONDARY_COLOR в .pipeline.

Что можно подкрутить:
- animation_step 50 в .pipeline — кадров станет ещё меньше (20 fps, стандарт kitty), но искры будут дёрганее.
- Меньше SPARK_COUNT и EMBER_LIFE — ещё меньше работы. Если увеличиваешь EMBER_LIFE, подними animation_stop так, чтобы он был не меньше EMBER_LIFE + 150 мс, иначе угольки замрут на последнем кадре.

Для сравнения: sparkle-plus станет заметно экономнее, если выключить ауру (var float AURA_INTENSITY = 0) и поставить animation_stop 900.
