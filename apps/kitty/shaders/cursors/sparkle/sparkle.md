# Sparkle cursor

Искрящийся курсор для kitty — три версии одного эффекта.

| Версия | Эффекты | Длительность после движения | Нагрузка |
|---|---|---|---|
| `sparkle-trail` | хвост, искры, взрыв при остановке | 0.9 с, 20 fps (~18 кадров) | средняя |
| `sparkle-plus` | всё из trail + градиент и блёстки, смазанные искры, угольки, кольцо, вспышка, аура | 3.3 с, 20 fps (~66 кадров) | высокая |
| `sparkle-lite` | почти всё из plus, кроме ауры и смазанных искр + звезда при остановке | 0.65 с, 30 fps (~20 кадров) | низкая |

Подключение в `kitty.conf` (нужна строка `cursor_trail 1`):

```
custom_shaders ~/dotfiles/apps/kitty/shaders/cursors/sparkle/sparkle-lite.pipeline
```

Работает с любой формой курсора: `cursor_shape block | beam | underline`.

---

## Как работает настройка

Всё настраивается в `.pipeline`, сам `.slang` трогать не нужно.

- `var <тип> <ИМЯ> = <значение>` переопределяет параметр шейдера. Тип должен совпадать с типом в шапке `.slang`, иначе строка **молча игнорируется**: `var int SPARK_COUNT = 30`, но `var float SPARK_LIFE = 0.5`. Точка с запятой в конце не мешает.
- `animation_stop <мс>` — сколько миллисекунд после движения курсора kitty перерисовывает окно. **Это главный расход энергии**: каждый кадр шейдер считается для каждого пикселя окна.
- `animation_step <мс>` — пауза между кадрами. 50 = 20 fps (стандарт kitty, если строки нет), 33 = 30 fps, 16 = 60 fps.
- Правило: `animation_stop` должен быть не меньше самого долгого эффекта, иначе он замрёт на последнем кадре:
  - trail: `SPARK_LIFE` + 0.15 с
  - plus: `AURA_DURATION` + 0.3 с
  - lite: `EMBER_LIFE` + 0.15 с
- Любой эффект с параметром `*_INTENSITY` выключается значением `0`.
- Полный список параметров с диапазонами — в шапке каждого `.slang`.

## Цвет (во всех трёх версиях)

```
var int COLOR_MODE = 1        # 0 = курсор темы, 1 = свои цвета, 2 = радуга
var float3 PRIMARY_COLOR   = float3(0.92, 0.74, 0.73)   # голова хвоста и часть искр
var float3 SECONDARY_COLOR = float3(0.77, 0.65, 0.91)   # хвост и остальные искры
var float3 HOT_COLOR       = float3(1.0, 0.92, 0.75)    # цвет только что вылетевших искр
var float RAINBOW_SPEED      = 0.25   # для радуги: оборотов цвета в секунду
var float RAINBOW_SATURATION = 0.75   # для радуги: 0 = белый, 1 = насыщенный
```

Цвета задаются как hex, делённый на 255: `#ebbcba` → `float3(0.92, 0.74, 0.73)`.
`COLOR_MODE = 0` берёт цвет курсора текущей темы omarchy и меняется вместе с темой.

## sparkle-trail

Файлы: `sparkle-trail.slang`, `sparkle-trail.pipeline`.

1. Светящийся хвост вдоль шлейфа kitty. Двигается по `cursor_trail_decay` из `kitty.conf`.
2. Искры вдоль пути: вылетают назад и в стороны, замедляются, падают и мерцают. Часть вспыхивает четырёхлучевыми звёздочками. Цвет остывает от `HOT_COLOR` до основного.
3. Взрыв искр в точке, где курсор остановился.

При наборе текста (сдвиг на одну клетку) искр немного, при длинных прыжках — полный поток.

**Оптимизировать:**
```
animation_stop 600
var int SPARK_COUNT = 20
var int BURST_COUNT = 6
var float SPARK_LIFE = 0.4
var float COMET_GLOW = 4
```

**Больше анимации:**
```
animation_step 16                 # 60 fps — плавнее
animation_stop 1300
var int SPARK_COUNT = 64
var int BURST_COUNT = 24
var float SPARK_LIFE = 1.0
var float FLARE_CHANCE = 0.6      # больше звёздочек
var float SPARK_GRAVITY = -4      # искры всплывают, а не падают
```

## sparkle-plus

Файлы: `sparkle-plus.slang` и три пайплайна: `sparkle-plus.pipeline` (цвет темы), `sparkle-plus-custom.pipeline` (два своих цвета), `sparkle-plus-rainbow.pipeline` (радуга).

Добавлено к trail:
1. Хвост с градиентом от головы к хвосту и мерцающими блёстками внутри.
2. Искры летят смазанными штрихами, как при длинной выдержке.
3. Угольки — медленные огоньки, которые всплывают и покачиваются.
4. Кольцо ударной волны с искрящимся краем от точки, куда прыгнул курсор.
5. Вспышка вокруг курсора на каждое нажатие клавиши.
6. Аура после остановки: пульсирующее свечение и огоньки, кружащие вокруг курсора. Гаснет за 3 с.

**Оптимизировать.** Больше всего энергии съедает аура, потому что из-за неё анимация идёт 3.3 с:
```
animation_stop 900
var float AURA_INTENSITY = 0
var float STREAK_LENGTH = 0       # искры точками вместо штрихов
var int SPARK_COUNT = 24
var int BURST_COUNT = 8
var int EMBER_COUNT = 6
var float GLITTER_INTENSITY = 0
```
Если ауру хочется оставить, лучше её укоротить:
```
animation_stop 1500
var float AURA_DURATION = 1.2
```

**Больше анимации:**
```
animation_step 16
animation_stop 4300
var float AURA_DURATION = 4.0
var int AURA_MOTES = 5
var int SPARK_COUNT = 64
var int EMBER_COUNT = 24
var float EMBER_LIFE = 2.0
var float RING_SIZE = 3.0
var float GLITTER_DENSITY = 0.25
```

## sparkle-lite

Файлы: `sparkle-lite.slang`, `sparkle-lite.pipeline`.

Эффекты: хвост с градиентом и блёстками, искры со звёздочками, угольки, взрыв и кольцо при длинном прыжке, звезда на курсоре при остановке, вспышка при наборе. Ауры нет.

Почему она экономнее:
1. **Анимация короче:** 0.65 с вместо 3.3 с у plus.
2. **Пиксели вдали от курсора отсекаются сразу** одной проверкой по прямоугольнику вокруг пути, а это почти всё окно.
3. **Меньше работы на частицы:** искр 18+8, угольков 5, один хэш на частицу, далёкие частицы отбрасываются до тяжёлых `exp`/`sin`.
4. **При наборе текста почти ничего не рисуется:** 3 искры, без кольца и угольков.

**Оптимизировать ещё сильнее:**
```
animation_step 50                 # 20 fps — искры дёрганее
animation_stop 500
var float SPARK_LIFE = 0.35
var float EMBER_LIFE = 0.35
var int SPARK_COUNT = 12
var int BURST_COUNT = 6
var float GLITTER_INTENSITY = 0
```

**Больше анимации** (всё ещё заметно легче plus):
```
animation_stop 1150
var float EMBER_LIFE = 1.0
var int EMBER_COUNT = 14
var int SPARK_COUNT = 30
var int BURST_COUNT = 12
var float SPARK_LIFE = 0.6
```
Плавнее, но дороже: `animation_step 16`.

## Ограничения

- kitty передаёт шейдеру только последнее перемещение курсора. Поэтому при быстром наборе искры от предыдущей клавиши пропадают, когда начинается следующее движение. Хвост при этом не обрывается.
- Пока шейдер подписан на `cursor-trail-move`, встроенный шлейф kitty не рисуется, его рисует сам шейдер. Поэтому `cursor_trail_color` из `kitty.conf` не действует, цвет задаётся через `COLOR_MODE`.
